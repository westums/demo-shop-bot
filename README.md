# 🛍 DemoShop — Telegram-бот магазина одежды (портфолио)

Демонстрационный Telegram-бот интернет-магазина одежды с полным циклом:
каталог → корзина → заказ → оплата (заглушка) → отслеживание статуса с уведомлениями.

> 💡 Проект создан как портфолио, не для коммерческого использования.
> Все заказы и платежи — демонстрационные.

## ✨ Возможности

- 👤 **Регистрация** с согласием на обработку персональных данных
- 🛍 **Каталог** с категориями, фото товаров и пагинацией
- 🛒 **Корзина** с изменением количества и удалением позиций
- 📦 **Оформление заказа** через пошаговый FSM-диалог
- 💳 **Оплата** — генерация демо-QR-кода (реальных платежей нет)
- 🔔 **Уведомления клиенту** при смене статуса заказа
- 🔧 **Демо-админка** — открыта всем желающим (портфолио-режим), показывает статистику и позволяет менять статусы заказов
- 🗑 **Удаление своих данных** одной кнопкой (соответствует обещаниям из согласия)
- 📝 **Логирование** в файл `bot.log`
- ⚠️ **Глобальный error handler** — не падаем на ошибках

## 🚀 Быстрый старт

### 1. Клонировать / скачать проект

```bash
git clone <твой_репозиторий>
cd shop_bot
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate    # Linux/macOS
.venv\Scripts\activate       # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить `.env`

Скопируйте `.env.example` → `.env` и вставьте токен от [@BotFather](https://t.me/BotFather):

```env
BOT_TOKEN=1234567890:AAH-ваш_токен
```

### 5. Запустить

```bash
python main.py
```

При первом запуске автоматически создаётся `shop.db` и засеиваются демо-товары.

## 🧪 Сценарий демонстрации

1. `/start` → принять согласие → зарегистрироваться
2. **🛍 Каталог** → выбрать категорию → товар → «В корзину»
3. **🛒 Корзина** → поменять количество через +/− → «Оформить заказ» → ввести адрес
4. Получить демо-QR-код, нажать «✅ Я оплатил»
5. Открыть **🔧 Админ-панель (демо)** → выбрать заказ → сменить статус
6. Получить уведомление как клиент 🎉
7. **👤 Профиль** → «🗑 Удалить мои данные» → подтвердить

## 🛠 Технологии

- **Python 3.13**
- **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
- **SQLite** через `aiosqlite`
- **qrcode + Pillow** — генерация демо-QR
- **python-dotenv** — конфигурация через `.env`

- разработки **асинхронных Telegram-ботов** на aiogram 3
- работы с **FSM** (машины состояний для регистрации и оформления заказа)
- проектирования **схемы БД** для интернет-магазина (пользователи, товары, корзина, заказы, позиции заказов)
- **UX-продумывания** пользовательских сценариев
- **обработки ошибок** и **логирования**
- **соблюдения приватности** (согласие на обработку ПД + удаление данных)
