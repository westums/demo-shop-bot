# 🛍 DemoShop — Telegram-бот магазина одежды

[![Python](https://img.shields.io/badge/Python-3.13-blue)](https://www.python.org/)
[![aiogram](https://img.shields.io/badge/aiogram-3.x-2CA5E0)](https://docs.aiogram.dev/)
[![SQLite](https://img.shields.io/badge/SQLite-3-003B57)](https://sqlite.org/)

> Демонстрационный Telegram-бот интернет-магазина одежды с полным циклом покупки — от выбора размера до уведомления о доставке. Портфолио-проект на **aiogram 3**.

🤖 **Попробовать бота:** [@clothes32_shop_bot](https://t.me/clothes32_shop_bot)

---

## ✨ Что внутри

- 👤 **Регистрация** с явным согласием на обработку ПД (152-ФЗ)
- 🛍 **Каталог** с категориями, фото, размерами и пагинацией
- 🛒 **Корзина** с изменением количества и выбором размера
- 📦 **Оформление заказа** через пошаговый FSM-диалог
- 💳 **Демо-оплата** с генерацией QR-кода (реальных транзакций нет)
- 🔔 **Уведомления** клиенту при смене статуса заказа
- 🔧 **Демо-админка** — открыта всем (портфолио-режим), со статистикой и сменой статусов
- 🗑 **Удаление своих данных** одной кнопкой (соответствует обещаниям из согласия)
- 📝 **Логирование** в файл + глобальный error handler

---

## 🎭 Чем этот проект отличается от типичного «магазина на aiogram»

**Главная фишка — клиент и «админ» в одном лице.** В демо-режиме любой может открыть «Админ-панель», найти свой заказ и нажать «📦 Отправлен» — и **сразу получить уведомление как клиент**. Так ревьюер вживую видит всю цепочку «смена статуса → push клиенту», а не просто читает код.

**Демо-заказы с маскировкой чужих данных.** В админке предзасеяны 3 «заказа от Александры Смирновой» с разными статусами — для атмосферы. Реальные чужие заказы показываются с маскировкой (`И. П.`, `+7 *** *** 47`), а менять статус можно только своих и демо-заказов.

**Доставка с логикой.** До 3 000 ₽ — 300 ₽ доставка, выше — бесплатно. Считается в корзине и входит в итог заказа.

**Согласие на ПД не для галочки.** Текст согласия, кнопка удаления всех данных, `/delete_me` — пользователь действительно может уйти и забрать всё с собой.

## 🚀 Быстрый старт

### Что понадобится

- **Python 3.13** (или 3.11+, код совместим)
- **Токен бота** от [@BotFather](https://t.me/BotFather) — `/newbot` → скопировать токен

### Шаг 1. Клонировать репозиторий

```bash
git clone https://github.com/westums/demo-shop-bot.git
cd demo-shop-bot
```

> Не используешь git? Скачай ZIP: **Code → Download ZIP** на странице репозитория.

### Шаг 2. Создать виртуальное окружение

**Linux / macOS:**
```bash
python3.13 -m venv .venv
source .venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

> Если PowerShell ругается на политику выполнения, один раз выполни:
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` → `Y`

### Шаг 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Ставится 5 пакетов: `aiogram`, `aiosqlite`, `python-dotenv`, `qrcode[pil]`, `Pillow`. Займёт ~30 секунд.

### Шаг 4. Настроить `.env`

Скопируй шаблон и вставь токен:

```bash
# Linux / macOS
cp .env.example .env

# Windows
copy .env.example .env
```

Открой `.env` любым редактором и вставь свой токен:

```env
BOT_TOKEN=1234567890:AAH...твой_токен_из_BotFather
```

⚠️ **Токен никому не показывай.** `.env` уже в `.gitignore`, в репозиторий он не попадёт.

### Шаг 5. Запустить

```bash
python main.py
```

**Что произойдёт при первом запуске:**

```
[INFO] __main__: Запуск бота...
[INFO] __main__: БД инициализирована, демо-данные засеяны
[INFO] __main__: Все роутеры подключены, старт polling...
[INFO] aiogram.dispatcher: Run polling for bot @твой_бот
```

- Создастся файл `shop.db` (SQLite) рядом с `main.py`
- Засеются 6 товаров в 4 категориях и 3 демо-заказа
- Создастся `bot.log` с логами

Открой бота в Telegram, нажми `/start` — поехали 🎉

### 🐳 Альтернатива: Docker

```bash
docker build -t demo-shop-bot .
docker run -d --name shop-bot \
  -v "${PWD}/data:/data" \
  --env-file .env \
  demo-shop-bot

# Логи
docker logs -f shop-bot
```

БД и логи будут в папке `data/` на хосте — не потеряются при перезапуске контейнера.

## 🧪 Сценарий демонстрации (для ревьюера)

1. `/start` → принять согласие → зарегистрироваться
2. **🛍 Каталог** → выбрать категорию → товар → размер → количество → «В корзину»
3. **🛒 Корзина** → оформить заказ → ввести адрес → **QR-код** → «Я оплатил»
4. **🔧 Админ-панель (демо)** → выбрать свой заказ → сменить статус на «📦 Отправлен»
5. **Получить уведомление** от бота (это и есть киллер-фича) 🎉
6. **👤 Профиль** → «🗑 Удалить мои данные» → подтвердить → `/start` снова (данные удалены)

## 🌐 Развёртывание

### Bothost (рекомендуется для РФ)

1. Собери ZIP без `.env`, `.venv`, `data/`, `shop.db`, `bot.log`
2. Bothost → «Загрузить из архива» → укажи токен → Deploy
3. На тарифах **Basic/Pro** подключи volume на `/data`, чтобы БД сохранялась между перезапусками

### VPS (Ubuntu)

```bash
git clone https://github.com/ТВОЙ_НИК/demo-shop-bot.git
cd demo-shop-bot
python3.13 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
echo "BOT_TOKEN=твой_токен" > .env
python main.py
```

Для автозапуска — systemd-юнит или `docker compose up -d`.
